SecureCall — Deine Stimme gehört nur dir.

SecureCall ist die erste Telefon-App, die von Grund auf für maximale Privatsphäre entwickelt wurde. Jeder Anruf wird Ende-zu-Ende verschlüsselt — mit militärischer Kryptografie, die selbst Geheimdienste nicht knacken können.

🔒 SICHERHEIT AUF HÖCHSTEM NIVEAU

• Ende-zu-Ende-Verschlüsselung mit XChaCha20-Poly1305 (AEAD)
• Schlüsselaustausch über X25519 (Elliptic Curve Diffie-Hellman)
• Double-Ratchet-Protokoll für Perfect Forward Secrecy
• Jeder Anruf hat einen einzigartigen Sitzungsschlüssel
• Kryptografie-Engine komplett in Rust geschrieben — speichersicher, keine Buffer Overflows
• Unabhängig auditiert

📞 KRISTALLKLARE ANRUFE

• Opus-Audio-Codec für natürliche Sprachqualität
• Optimiert für niedrige Latenz, auch bei schlechter Verbindung
• Funktioniert über WLAN und Mobilfunk

🛡️ ZERO METADATA

• Keine Anrufprotokolle auf unseren Servern
• Keine Kontaktlisten-Uploads
• Kein Tracking, keine Werbung
• Kompatibel mit VPN-Verbindungen, die Android oder eine vertrauenswürdige App verwaltet

📖 SOURCE AVAILABLE

Der komplette Quellcode ist auf GitHub einsehbar. Jeder kann die Sicherheit verifizieren — Vertrauen durch Transparenz.

TECHNISCHE DETAILS

Verschlüsselung: XChaCha20-Poly1305 (AEAD)
Schlüsselaustausch: X25519 (ECDH)
Forward Secrecy: Double Ratchet Protocol
Audio: Opus Codec (6-510 kbps)
Transport: WebRTC/QUIC mit DTLS
Krypto-Engine: Rust (speichersicher)
Netzwerk: WebRTC mit STUN/TURN; kompatibel mit vom Gerät verwalteten VPNs
