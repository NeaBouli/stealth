FAQ

Which APK should I download?
Almost all phones from 2016 onwards use arm64-v8a. Only very old devices need armeabi-v7a. If unsure, try arm64 first.
Do I need a Pro/Premium license key?
Pro and Premium can be activated through a valid subscription or activation code. IFR holders can verify a browser wallet for a 50% Stripe checkout discount, not an in-app wallet unlock.
How do I verify the APK signature?
All builds are signed with the SecureCall release keystore. Check the GitHub release for SHA256 checksums.
