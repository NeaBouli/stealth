FAQ

Which APK should I download?
Download the universal APK above. It contains the supported Android CPU variants, so customers do not need to choose between separate APK files.
Where are the Pro and Premium APKs?
You do not need separate Pro or Premium APKs. Install the public APK above, then enter your activation code in Settings. The app switches to the highest valid plan on the device.
Do I need a Pro/Premium license key?
Pro and Premium are activated through a valid subscription or activation code. IFR holders can verify a browser wallet for a 50% Stripe checkout discount, not an in-app wallet unlock.
How do I verify the APK signature?
All builds are signed with the SecureCall release keystore. Check the GitHub release for SHA256 checksums.
