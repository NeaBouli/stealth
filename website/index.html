End-to-End Encryption

XChaCha20-Poly1305 AEAD encryption with X25519 key exchange. Every call gets a unique session key. We can never listen in.

Zero Metadata

No call logs, no contact uploads, no tracking. Your IP is masked through GhostNet relays. We store nothing about your communication.

Source Available

The complete source code is on GitHub. Don't trust — verify. Anyone can audit our security claims.

Rust Crypto Engine

The cryptography core is written in Rust for memory safety. No buffer overflows, no use-after-free. Independently audited.

Crystal-Clear Audio

Opus audio codec delivers natural voice quality even on poor connections. Optimized for low latency across WiFi and cellular.

Perfect Forward Secrecy

Double Ratchet protocol ensures that compromising one key doesn't expose past or future calls. Every session is independent.
