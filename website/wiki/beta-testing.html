Beta Testing Guide

Install, test, and report bugs during the beta testing phase.

SecureCall beta testing procedures · Last updated March 2026

1. Install the App

  • Receive email invitation from Google Play
  • Open the link in the email
  • Tap “Join the test”
  • Install the app from the Play Store

2. Set Up the App

  • Open the app → Complete onboarding (4 screens)
  • Enter your phone number and save
  • Grant permissions (microphone, notifications)
  • Done — the app is ready to use

3. Upgrade the App (for advanced testing)

Settings → Enter Activation Code:

Pro VersionTEST-PRO1-CODE
Premium VersionTEST-PREM-CODE

4. Install Updates

  1. Open the Play Store
  2. Tap your profile picture (top right)
  3. Open “Manage Apps & Device”
  4. SecureCall → Tap “Update”

5. Connect with Other Testers

Method A — Invite Link

  1. Settings → Copy “Your SecureCall ID”
  2. Send link via SMS/WhatsApp: stealthx.tech/invite/YOUR-ID
  3. Recipient opens link → App saves contact automatically

Method B — Manual

  1. Settings → Copy “Your SecureCall ID”
  2. Send ID via SMS
  3. Recipient: Contacts → Search → Enter SecureID

6. Report Bugs

Please report bugs via:

  • GitHub Issues
  • Email to the developer

Bug reports should include:

  • Device + Android version
  • App version (Settings → About)
  • Steps to reproduce
  • Screenshot if possible

Known Limitations (Beta)

  • App displays “com.securecall.app.free” as package name
  • WireGuard VPN requires own server configuration
  • App not yet in public Play Store

What to Test

  • Encrypted calls between different devices
  • Add contacts (manual + Invite Link)
  • Settings persist after app restart?
  • Upgrade to Pro/Premium via activation code
  • Toggle Dark/Light mode
  • Navigation bar overlaps app? (Samsung S21+)
