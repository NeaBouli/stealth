Beta Testing Guide

1. App installieren

  • Email-Einladung von Google Play erhalten
  • Link in der Email öffnen
  • “Am Test teilnehmen” klicken
  • App im Play Store installieren

2. App einrichten

  • App öffnen → Onboarding (4 Screens) durchlaufen
  • Telefonnummer eingeben und speichern
  • Berechtigungen erlauben (Mikrofon, Benachrichtigungen)
  • Fertig — App ist einsatzbereit

3. App upgraden (für erweiterte Tests)

Settings → Activation Code eingeben:

Pro VersionTEST-PRO1-CODE
Premium VersionTEST-PREM-CODE

4. Updates installieren

  1. Play Store öffnen
  2. Profilbild oben rechts tippen
  3. “Apps & Gerät verwalten” öffnen
  4. SecureCall → “Aktualisieren” tippen

5. Kontakt zu anderen Testern herstellen

Methode A — Invite Link

  1. Settings → “Your SecureCall ID” kopieren
  2. Link per SMS/WhatsApp senden: stealthx.tech/invite/DEINE-ID
  3. Empfänger öffnet Link → App erkennt Kontakt automatisch

Methode B — Manuell

  1. Settings → “Your SecureCall ID” kopieren
  2. ID per SMS senden
  3. Empfänger: Kontakte → Suche → SecureID eingeben

6. Bugs melden

Gefundene Bugs bitte melden via:

  • GitHub Issues
  • Email an den Entwickler

Bug-Bericht sollte enthalten:

  • Gerät + Android Version
  • App Version (Settings → About)
  • Schritte zum Reproduzieren
  • Screenshot falls möglich

Bekannte Einschränkungen (Beta)

  • App zeigt “com.securecall.app.free” als Paketnamen
  • WireGuard VPN braucht eigene Server-Konfiguration
  • App noch nicht im öffentlichen Play Store

Was getestet werden soll

  • Verschlüsselte Anrufe zwischen verschiedenen Geräten
  • Kontakte hinzufügen (manuell + Invite Link)
  • Einstellungen speichern (nach App-Neustart noch vorhanden?)
  • Upgrade auf Pro/Premium via Aktivierungscode
  • Dark/Light Mode wechseln
  • Navigationsleiste überlappt App? (Samsung S21+)
