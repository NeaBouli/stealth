SecureCall version history and changelog · Last updated April 3, 2026

All notable changes to the SecureCall project. Versions in reverse chronological order. 20 tests verified on 3 physical devices (S10 Premium, S7 Pro, Tab S4 Free).
v1.0.12 (versionCode 30) — April 2, 2026

BUG-028 through BUG-032 + Website Audit

  • BUG-028: Dark mode not active after OTA update
  • BUG-029: TURN TCP/TLS fallback for VPN compatibility
  • BUG-030: Audio volume fix on affected devices
  • BUG-031: Verify dialog shown after call ends
  • BUG-032: Ring timeout 60s + OkHttp ping 15s (was 5s, too aggressive for VPN)
  • Long-press contact → Verify / Block / Delete menu
  • User Manual page linked from Settings → About
  • SecLog enhanced: ICE/TURN/Audio/Stats events
  • 73 website inconsistencies fixed (prices, legal, versions, devices, dates)
v1.0.12 (versionCode 29) — April 1, 2026

Call Stability + VPN Support

  • OkHttp ping interval 5s → 15s (VPN-friendly)
  • TURN TCP/TLS fallback for restrictive networks
  • HeartbeatClient anti-flap recovery mode
  • Call stability improvements
v1.0.12 (versionCode 28) — March 30, 2026

IFR + Upgrade Polish

  • IFR token link click handler fixed
  • Upgrade button tier-aware: hidden for Premium, “Upgrade to Premium” for Pro
  • CollapsiblePreferenceCategory respects programmatically hidden prefs
  • Update mirror: release→Play Store, debug/sideload→GitHub
v1.0.12 (versionCode 24) — March 29, 2026

Bug Sprint + Feature Polish

  • Dark mode as default for new installs
  • Connect/Disconnect button with color indicator (green/grey/yellow)
  • Settings sections collapsible with arrow (tap ▶ expand, ▼ collapse)
  • Auto-reconnect on network change (ConnectivityManager NetworkCallback)
  • Phone normalization (+49, 0049, +49 151 234 567 all treated as same number)
  • Diagnostic logs + CSV export via Share Sheet (Pro/Premium)
  • Samsung A-series battery kill protection (WakeLock, AlarmManager, BootReceiver)
  • eSIM routing + Preferred Network marked Coming Soon (needs VpnService)
  • Emergency Delete first in Settings, IFR Token last
  • “Anonymous Network” renamed to “Network”
  • FAB hidden in all tabs except Dialer
  • Report a Bug opens stealthx.tech/wiki/bug-report.html
  • Matrix Integration wiki page + roadmap entries
  • 14+ bugs fixed (BUG-009 through BUG-025)
v1.0.11 (versionCode 22) — March 28, 2026

Invite System + Connect Button

  • Deep link invite “Open in SecureCall”
  • QR Code invite (ZXing library)
  • Contacts: online first, offline below
  • EBS rounded buttons + Template 11 Announcements
  • Disconnect button with color indicator
  • SecLog diagnostic logs (Pro/Premium)
  • Samsung Lock Screen fullScreenIntent fix
v1.0.10 (versionCode 21) — March 28, 2026

Invite System + Contact Improvements

  • Deep Link Invite system (securecall://add-contact)

  • Impressum: contact form + 24100 Kalamata address

FCM + Emergency Delete + Labels

  • FCM Token persistence across legacy hosting redeploys
  • Emergency Delete (STEALTH-DELETE) — 5-tap instant wipe
  • Pro/Premium feature labels + upgrade hints
  • FLAG_SECURE tier-based (Free=off, Pro=toggle, Premium=always)
