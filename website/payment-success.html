Checkout Return

SecureCall is confirming the payment with Stripe.
An activation code is issued only after the signed payment event is verified.

What happens next

  1. Stripe confirms the completed payment to SecureCall
  2. The server validates the signed notification
  3. Your activation code is sent to the checkout email address
  4. Enter the code under Settings > Activation Code

Returning to this page alone does not confirm a payment. If no activation code arrives, check the payment status and contact support instead of repeating the checkout.
