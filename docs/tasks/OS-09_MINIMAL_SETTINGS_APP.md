# OS-09 – Minimal Settings App

## Ziel
Entwicklung einer stark reduzierten Einstellungs-App für BlackRoot.

## Muss enthalten:
- Funkprofile (read-only)
- Gerätestatus
- SecureCall Policy-Status
- Update-Funktion für OS
- Debug-Logs (nur technisch, lokal)

## Darf NICHT enthalten:
- Google Accounts
- Entwickleroptionen
- App-Management
- WLAN-Hotspot
- Bluetooth
- NFC
- Ortungsdienste

## Tests
- App öffnet stabil
- keine versteckten Menüs
- keine Debug-Menüs außer „Systemstatus“
