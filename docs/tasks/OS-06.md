# TASK: OS-06 – Baseband Isolation & Radio Lockdown Layer

## 1. Ziel des Tasks
Entwicklung einer OS-Level-Schicht, die das Baseband (Modem) kontrolliert,
isoliert und vor unbefugtem Zugriff schützt. Ziel ist es, Funkangriffe wie
IMSI-Catcher, Baseband-Downgrade, stille Anrufe/SMS und bösartige Carrier-Manipulationen
bestmöglich zu verhindern.

Dieser Task ist extrem sicherheitsrelevant und betrifft ausschließlich die
Premium- und Military-Edition (PhantomLine Elite & GHOSTOS BlackRoot).

---

## 2. Funktionen des Radio Lockdown Layers

### 2.1 Erzwingen sicherer Funkprofile
Das OS muss definierte Sicherheitsprofile erzwingen:

**GhostProfile A – Ultra Secure (Default für OS):**
- LTE-only (4G)
- 2G vollständig deaktiviert
- 3G vollständig deaktiviert
- VoLTE aus
- kein Circuit-Switched-Fallback
- keine SMS-Funktion

**GhostProfile B – Secure:**
- LTE/5G erlaubt
- 2G/3G blockiert
- VoLTE optional

**GhostProfile C – Stealth Mode:**
- GSM ON für Tarnung
- echter Call läuft über GhostNet
- GSM-Audio komplett blockiert

Profile werden verwaltet über:
/sys/ghostos/radio_profile

### 2.2 Baseband Access Blocker
Der Kernel muss sicherstellen, dass:

- **nur systeminterne Dienste** die Radio-API verwenden dürfen  
- **keine App außer SecureCall** Modem-Infos abrufen darf  
- alle anderen Zugriffe → `EPERM` (Permission Denied)

Umsetzung über:

- SELinux Policies  
- Custom Binder Hooks  
- Permission Enforcement (RILD/ModemDaemon)

---

### 2.3 Downgrade & Manipulationsschutz
Das System erkennt:

- erzwungene 2G-Downgrades  
- ungewöhnliche Frequenzbänder  
- auffällige Cell-IDs  
- wechselnde LAC/MCC/MNC-Muster  

Wenn erkannt:

- OS erzeugt „High Risk“-Warnung  
- SecureCall darf entscheiden:
  - Call blockieren
  - Call unterbrechen
  - GhostNet-only zulassen

---

### 2.4 Silent SMS & Hidden Paging Filter
State-level Angriffe nutzen häufig:

- Stille SMS  
- Paging Requests  
- Location Updates  

Der Lockdown Layer muss:

- alle „Silent SMS“-Pattern blockieren  
- Paging Requests filtern  
- verdächtige LURs (Location Update Requests) melden  
- niemals Metadaten speichern

---

### 2.5 Baseband Watchdog
Kernel-Dienst, der:

- Modem-Status permanent prüft  
- unerwartete State-Änderungen meldet  
- Reboots des Modems erkennt  
- Befehlssatz-Missbrauch (AT-CMD) unterbindet

## 6. Q&A

**F:** Können Apps diese Einschränkungen umgehen?  
**A:** Nein. Radio-Zugriffe laufen über SELinux + Binder Hooks – Userland kann es nicht umgehen.

**F:** Warum 2G/3G blockieren?  
**A:** Diese Standards sind unsicher, extrem anfällig für IMSI-Catcher und bieten keine moderne Verschlüsselung.

**F:** Wie zuverlässig ist Silent-SMS-Detection?  
**A:** Sehr hoch, da Silent-SMS definierte Protokollmuster verwenden, die gefiltert werden können, bevor sie die Telephony-API erreichen.

**F:** Erhöht dies den Akkuverbrauch?  
**A:** Minimal – die meisten Checks hängen an existierenden Kernel-Events.
