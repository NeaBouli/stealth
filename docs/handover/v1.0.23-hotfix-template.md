## 6. Build + Deploy Checkliste

```bash
# 1. Auf Hotfix-Branch wechseln
git checkout release/v1.0.23-hotfix

# 2. Fixes implementieren + committen (atomar pro Fix)

# 3. Lokal testen (S10, S7, Tab S4)

# 4. AAB bauen
cd client_android
./gradlew bundleFreeRelease -x lint

# 5. Signatur + Version verifizieren
aapt dump badging app/build/outputs/bundle/freeRelease/app-free-release.aab | grep version

# 6. APK für Sideload-Test
./gradlew assembleFreeRelease -x lint

# 7. SHA-256 Hashes berechnen + in Release-Notes
shasum -a 256 app/build/outputs/bundle/freeRelease/*.aab

# 8. Play Console Upload (manuell)

# 9. Tag setzen
git tag -a v1.0.23 -m "Hotfix v1.0.23 — [Beschreibung]"

# 10. Merge zurück in main
git checkout main
git merge release/v1.0.23-hotfix
git push origin main --tags
```
