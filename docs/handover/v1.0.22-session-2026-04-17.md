## 2. Root Cause — Connection-Loop P0

**Ursache:** Commit `d6cb024` (15.04.2026) fügte App-Signatur-Prüfung beim
REGISTER hinzu. Die Railway Env-Var `ALLOWED_SIGNATURES` wurde gesetzt (aus
`docs/PLATFORM_TODO.md` abgearbeitet), obwohl das installierte APK (v1.0.21,
vC42) den neuen `getAppSignature()`-Code noch nicht enthielt.

**Server-Seite:** `ALLOWED_SIGNATURES` → leere `appSignature` → `close(4003)`
**Client-Seite:** Reconnect-Loop alle 4s mit denselben (fehlenden) Credentials

**Fix:** Railway Env-Var `ALLOWED_SIGNATURES` via GraphQL API gelöscht.
Server-Code ist rückwärtskompatibel: kein Env-Var = alle Clients erlaubt.

**Verifiziert:** Railway-Logs zeigen 5+ User-IDs registrieren erfolgreich,
S10-Logcat zeigt keine `unauthorized_client`-Errors mehr.
